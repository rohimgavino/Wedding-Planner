# EverRae visual preferences

## Scope
This project follows the user-supplied DESIGN (2).md as a visual preference for EverRae only. The document attributes its religious interpretation to Syaikh Atha bin Khalil Abu ar-Rasytah. This is not a claim of universal scholarly consensus, not a new service-wide religious policy, and not an instruction to modify global Hermes configuration.

## Implementation choice
Use a conservative non-animate-subject selection: landscapes, mountains, lakes, trees, flowers, empty architecture, stationery, rings, and decor. Do not introduce visible humans, animals, portraits, or figurative statues in project photography. Use licensed source photographs and retain exact source and license records. No generated human/animal imagery or face/clothing manipulation.

Preserve the existing premium forest-green/ivory palette, serif composition, responsive crops, and product interactions. Replace the photograph, not the app/auth/storage logic.

## Asset review checklist
1. Fetch source page and verify author, photo identity, and license; do not infer provenance from filenames.
2. Inspect the full image, including background, reflections, and edges. Reject any visible person, animal, hand/body part, portrait, or figurative statue even if the title says empty venue.
3. Update alt text and both legal-page and repository credits. Remove superseded assets when no source references remain.
4. Build, lint, type-check, then verify complete/naturalWidth for all rendered images, overflow at 360/390/430/1440px, and unchanged demo interactions/storage.
